2. Bugs Found & Fixed During This Audit

Missing Expense Management Methods
admin.js — lines 1270–1340 (added)
The HTML had a "Save Record" button calling CK.admin.saveExpense(), and init() called this.loadExpenses() and this.openExpenseModal(), but none of these 3 methods existed. Clicking "Add Expense" in the admin panel would crash. Added loadExpenses(), openExpenseModal(), saveExpense(), and deleteExpense() — all wired to CK.db.saveExpense() and the correct HTML form field IDs.
FIXED Severity: Critical
Missing viewCoachDetails() Method
admin.js — after line 1436 (added)
CK.admin.viewCoachDetails(id) was called from 3 places (coach table rows, "View Details" button, live panel icon) but the method never existed. Clicking any coach row in the admin panel would throw TypeError: CK.admin.viewCoachDetails is not a function. Added full implementation that populates the coach details modal with real data.
FIXED Severity: Critical
Keyboard Shortcut Targeting Wrong Element ID
main.js — line 1570
Ctrl+K shortcut looked for getElementById('adminSearch') but the actual HTML element is id="adminGlobalSearch". The shortcut would never focus the search box — it always fell through to the toast message instead.
FIXED Severity: Medium
Unsafe Direct DOM Access in Vault Inline Script
index.html — lines 6156–6173
The inline CK.openVaultSession() and CK.seekVaultMove() used document.getElementById(...).textContent without null checks, risking TypeError if elements were missing. Also, the analysis parameter in seekVaultMove was injected via innerHTML without XSS escaping. Fixed both issues — added null guards and CK.esc() sanitization.
FIXED Severity: Low/Security

9. Recommendations

1. Deploy & Test Live: Push the updated code to Vercel. The service worker cache bump (ck-v5) will auto-refresh assets for returning users. Test the Admin → Expenses panel and Coach → View Details first.

2. Enable Supabase RLS: Ensure Row Level Security policies are active on all tables (profiles, attendance, expenses, documents) to prevent unauthorized data access via the public ANON key.

3. Replace Razorpay Test Key: The config uses rzp_test_REPLACE_WITH_YOUR_KEY — swap this with your live Razorpay key before accepting real payments.

4. Add CSP Headers: Configure Content-Security-Policy headers on Vercel to restrict script sources and prevent potential XSS from CDN compromise.

5. Consider Code Splitting: The SPA loads all 24 JS files upfront. For better performance on slow connections, consider lazy-loading portal-specific modules (arena.js, arcade.js) on demand.
